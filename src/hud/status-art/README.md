# GemTD status artwork

These 64px transparent icons are rendered from the original canvas artwork in
`jvsperds/GemTD`, `src/icons.ts`, with its `src/render.ts` outline helper.
The upstream MIT licence is included in this directory.
Source revision: `e4efd22e0b264eea937f2e81989da3efd641d9da`.

The family names preserve the predecessor's colourful silhouettes: frost, poison,
aura, split, speed, shield, stun and the other existing ability families. Facet TD
maps its existing status keys to those families; effects and values are unchanged.

Generated locally with Chromium Canvas 2D on 5 November 2026. Source repository:
https://github.com/jvsperds/GemTD
