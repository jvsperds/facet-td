# Facet TD — mineral and stone

P1.5 direction sheet · 25 October 2026 · Baseline for P2–P4.

**Cave-grey UI, slate board, pale grey actions and saturated gems.** Cave scenery is the theme; detailed background art remains deferred. The user supplied a board-first UI reference, then chose a cave-like theme and grey UI tones. The world fills the screen; compact panels float in safe corners.

| Choice | Direction |
| --- | --- |
| Camera | Two toggleable orthographic views: **Isometric** at 45° azimuth and **35.264° elevation** (1.732:1 ground diamonds), and **Top** at **90° elevation**, with a square, north-up grid at zero rotation. Default to a fixed angle. Unlock rotation to orbit the board horizontally; lock again to hold the chosen angle. Top view rotates in its own plane. Preserve logical cells and the selected gem. |
| Shading | Opaque, flat-shaded low-poly meshes. Warm key light, neutral fill, small contact shadows. No bloom, metal reflections or surface noise. |
| Palette | Slate cells `#C7CAC9` / `#BCC2C2`, provisional backdrop `#656D74`, charcoal HUD `#25282C`, raised controls `#393E43`, text `#F4F3EF`, secondary text `#BDC3C7`, pale grey action `#D4D8DC` with dark ink `#202429`. Gem colours retain their type meaning. |
| States | Charcoal `#3C454C` selected-cell rim with a pale outer edge on the board. Separate blue `#164FAD` ground focus ring; white dashed focus on dark HUD. Danger uses `#FFB3AF` on dark panels plus explicit text. |
| Scale | One cell = one world unit. Complete model width ≤**0.68 cell**, tower height ≤**1.16 cell** at huge quality. A tower may hide only the cell diagonally behind it (measured from normal quality up); P2 must reveal that cell when it holds the selection or a creep; walls ≤**0.20 cell**: dark continuous rock ridges with a jagged crest. A tower stands on its cell's stone, which joins neighbouring walls. Effects cannot hide the selected cell. |
| Creeps | Body length **0.36 × VPK ModelScale** cell, keeping the original size ratios: 0.36 for wave 1, 0.79 at the late-wave 2.2, 1.8 for a 5.0 boss. Height is 0.66 × length, so even the smallest creep stands above walls and shows its top over any single tower in the four default views. Ground creeps up to 5.0 clear the walls of a one-cell corridor. Air units fly at **1.35 cell**, above every tower, with a ground shadow marking their cell. Light boxy bodies with dark trim separate creeps from dark rock and saturated gems. Health bars float just above each body as HUD overlays; bosses also show their HP number. Large creeps can hide towers behind them; P2 must keep the selected tower readable. |
| Type | Eight distinct tower and gem silhouettes (claw-set brilliant, column, waisted, keep, spire, cup, stepped, drum) and upright VPK letter stamps: D, B, Y, R, G, E, Q, P. Colour reinforces identity. |
| Quality | Six tiers: chipped, flawed, normal, flawless, perfect, huge. Each tier scales the tower above its stone base uniformly: width 0.38 / 0.44 / 0.50 / 0.56 / 0.62 / 0.68 cell, height cap 0.65 / 0.75 / 0.85 / 0.96 / 1.06 / 1.16 cell. Full name and tier number remain in the inspector. |
| Typography | Local Segoe UI / Arial, 16 px body, 14 px secondary labels, tabular numerals. Minimum 48 × 48 px controls with 8 px gaps. |

**Desktop:** compact top status bar; full-screen arena with build guidance upper left with **five selectable placement slots**, selection info lower left and an **icon-only toolstrip lower right**. Fit playable cells around measured HUD exclusion zones. If they overlap, dock or collapse the inspector and refit. Recipes open on demand. **Tablet:** collapsible inspector. **Phone portrait:** two status rows, five placement slots, board, compact icon row and selection sheet. Secondary tools sit in More. **Short landscape:** board left, 240 px scrollable inspector right; sticky action row. Respect safe areas and 320 px screens.

**Environment connection:** embed the arena in continuous cave floor. A tunnel feeds the logical northwest start; a single stone approach starts **at E** and leads outward into the defended stronghold. Checkpoint **2 must have no approach or branch to the castle**. The [five camera studies](camera-studies/README.md) show this connection at all four quarter-turns and in top view. Keep these connections attached to world coordinates through rotation and top view. Avoid an isolated platform or void moat. A fortified crystal vault is the proposed cave-themed representation of the original castle. The original route is S → 1 → 2 → 3 → 4 → 5 → castle; reaching the goal reduces castle HP. Do not add a sixth intermediate checkpoint.

**Placement summary:** each of five slots mirrors a gem actually placed this round. Show its silhouette and type/quality stamp. Selecting a slot selects that same gem on the board, reveals it above overlays and updates the lower-left info panel. Empty slots are disabled. A selected slot has a distinct outline. This is quick selection, not a separate drafting mechanic.

**Camera controls:** a 48 px view icon switches Isometric / Top; a lock icon switches Fixed angle / Rotate. Icons have action-specific accessible names and focus/touch-accessible tooltips. Desktop rotation uses drag in the Rotate tool; touch uses the same tool, with turn-left/right buttons as gesture-free alternatives. Locking holds the current angle; Reset view returns the default angle. Retain the selected cell, logical pan anchor, rotation angle and zoom relative to each view's fit. Refit around HUD panels after switching. The toggle changes presentation only.

**Input:** tap selects; a labeled action confirms. Arrow keys move one board cursor; Enter selects; Escape closes the top panel. Preserve selection and focus when panels change. A DOM cell inspector exposes equivalent commands and status announcements. Reduced motion removes camera easing and decoration. At overview zoom, use the inspector rather than relying on tiny silhouettes.

**Inspiration:** [user-supplied UI](references/user-ui.png). Adopt its board-first composition, bright board, charcoal floating panels and grouped icon controls. Exact values, costs, assets and mechanics come from Classic data.
